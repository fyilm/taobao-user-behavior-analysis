# 数据字典 / 字段说明

> 所有分析结果 CSV 位于 `output/tables/`，下表逐一解释每列含义。

## 一、通用字段（多张表共用）

| 字段 | 含义 |
|------|------|
| `pv` | 浏览（page view）行为，可能是「次数」或「去重用户数」，视所在表而定 |
| `cart` | 加购（加入购物车）行为 |
| `fav` | 收藏（加入收藏夹）行为 |
| `buy` | 购买（下单）行为 |
| `intent` | 加购 + 收藏的合并口径（「产生意向」） |
| `conversion_rate` | 转化率，**小数**，×100 即为百分比 |
| `loss_rate` | 流失率 = 1 − 转化率，**小数** |

## 二、漏斗相关表

### funnel_event_level.csv —— 事件级漏斗（按行为次数）
| 列 | 含义 |
|----|------|
| `stage` | 环节英文标识（pv / intent / cart / fav / buy） |
| `stage_name` | 环节中文名（浏览 / 加购/收藏 / 加购 / 收藏 / 购买） |
| `events` | 该环节的**行为总次数**（全网 9 天累计） |

### funnel_event_conversion.csv —— 事件级转化率 / 流失率
| 列 | 含义 |
|----|------|
| `path` | 转化路径，如 `pv→cart` = 浏览到加购 |
| `conversion_rate` | 该路径转化率（小数） |
| `loss_rate` | 该路径流失率（小数） |

### funnel_overall.csv —— 用户级漏斗（按去重用户）
| 列 | 含义 |
|----|------|
| `stage` / `stage_name` | 环节标识 / 中文名 |
| `users` | **有多少个用户**产生过该行为（去重，一人只算一次） |

### funnel_conversion_rates.csv —— 用户级转化率
| 列 | 含义 |
|----|------|
| `path` | 转化路径（用户口径） |
| `conversion_rate` | 转化率（小数） |

### funnel_daily.csv —— 按日漏斗
| 列 | 含义 |
|----|------|
| `date` | 日期 |
| `pv` / `cart` / `fav` / `buy` | 当天产生该行为的**去重用户数** |
| `pv_to_buy_rate` | 当天「浏览→购买」转化率（%） |
| `pv_to_cart_rate` | 当天「浏览→加购」转化率（%） |

### funnel_category_top10.csv —— TOP10 类目漏斗
| 列 | 含义 |
|----|------|
| `category_id` | 类目 ID |
| `pv` / `cart` / `fav` / `buy` | 该类目下产生该行为的**去重用户数** |
| `pv_to_buy_rate` | 该类目「浏览→购买」转化率（%） |

### behavior_hour.csv —— 24 小时行为分布
| 列 | 含义 |
|----|------|
| `hour` | 小时（0–23，0 点 = 凌晨 12 点） |
| `pv` / `cart` / `fav` / `buy` | 该小时内发生的**行为次数** |

## 三、RFM 相关表

### rfm_segments.csv —— RFM 分群汇总
| 列 | 含义 |
|----|------|
| `segment` | 客户分群名称（8 类，见下方术语） |
| `users` | 该分群用户数 |
| `avg_recency_days` | 平均 R：距用户最后一次行为的平均天数（**越小越活跃**，0 = 最后一天还有行为） |
| `avg_frequency` | 平均 F：9 天内平均行为总次数（越活跃越大） |
| `avg_monetary` | 平均 M：平均购买次数（无金额字段，以此作消费力代理） |
| `pct` | 该分群占总用户的比例（%） |

### rfm_score_distribution.csv —— RFM 分数组合分布
| 列 | 含义 |
|----|------|
| `r_score` | R 得分（1–5，5 = 最近活跃） |
| `f_score` | F 得分（1–5，5 = 最高频） |
| `m_score` | M 得分（1–5，5 = 购买最多） |
| `users` | 该分数组合的用户数 |

### rfm_user_level.csv —— 用户级 RFM 明细（59MB，钻取用，不入库）
| 列 | 含义 |
|----|------|
| `user_id` | 用户 ID |
| `recency_days` | R：距末次行为天数 |
| `frequency` | F：行为总次数 |
| `monetary` | M：购买次数 |
| `r_score` / `f_score` / `m_score` | 各维 1–5 得分 |
| `segment` | 分群名称 |
| `pv_cnt` / `cart_cnt` / `fav_cnt` / `buy_cnt` | 各行为次数 |

## 四、术语

| 术语 | 说明 |
|------|------|
| 事件级 | 按「行为次数」统计（一条行为记一次），用于看流量损耗 |
| 用户级 | 按「去重用户」统计（一人只算一次），用于看多少人转化 |
| 转化率 | 下一环节量 ÷ 上一环节量（如 加购次数 ÷ 浏览次数） |
| 流失率 | 1 − 转化率，即在该环节「掉了」的比例 |
| 加购/收藏（intent） | 加购与收藏合并，统称「意向行为」 |
| R（近度） | Recency，距最后一次行为的天数，越小越活跃 |
| F（频次） | Frequency，行为总次数，越大越活跃 |
| M（消费） | Monetary，本数据无金额，用「购买次数」作代理 |
| R/F/M 高、低 | 相对全量中位数的二值化：高 = 优于中位数 |

## 五、RFM 8 分群命名规则

分群名 = R高/低 × F高/低 × M高/低 的组合：

| R(近) | F(频) | M(买) | 分群名 |
|:---:|:---:|:---:|------|
| 高 | 高 | 高 | 重要价值客户 |
| 高 | 高 | 低 | 一般价值客户 |
| 高 | 低 | 高 | 重要发展客户 |
| 高 | 低 | 低 | 一般发展客户 |
| 低 | 高 | 高 | 重要保持客户 |
| 低 | 高 | 低 | 一般保持客户 |
| 低 | 低 | 高 | 重要挽留客户 |
| 低 | 低 | 低 | 一般挽留客户 |

> 「保持/挽留」类 = R 低（最后一天已无行为），即已出现流失迹象的客户。
